\# 1. Purpose



Acest document conține definițiile oficiale ale termenilor utilizați în cadrul ESTINVEST Ecosystem.



Scopul este utilizarea unei terminologii comune în toate aplicațiile, documentele și proiectele.



\---



\# 2. Business Terms



\## Account



Cont operațional utilizat pentru administrarea activelor și disponibilităților unui client.



\---



\## Portfolio



Grup logic de instrumente financiare și poziții asociate unui cont.



\---



\## Customer



Persoană fizică sau juridică ce utilizează serviciile ESTINVEST.



\---



\## Application



Cererea de deschidere a unui cont inițiată prin aplicația Onboarding.



\---



\## Beneficial Owner



Persoana care deține sau controlează în ultimă instanță clientul.



\---



\## Broker



Persoană autorizată să intermedieze ordinele clienților.



\---



\## Trader



Utilizator responsabil pentru transmiterea și executarea ordinelor în piață.



\---



\## Settlement



Procesul de decontare a tranzacțiilor după executare.



\---



\## Custody



Serviciul de păstrare și administrare a instrumentelor financiare ale clienților.



\---



\# 3. Regulatory Terms



\## KYC (Know Your Customer)



Procesul de identificare și verificare a identității clientului.



\---



\## AML (Anti-Money Laundering)



Ansamblul procedurilor pentru prevenirea și combaterea spălării banilor.



\---



\## PEP (Politically Exposed Person)



Persoană expusă politic, conform legislației aplicabile.



\---



\## FATCA



Reglementare fiscală privind raportarea conturilor deținute de persoane americane.



\---



\## CRS (Common Reporting Standard)



Standard internațional pentru schimbul automat de informații fiscale.



\---



\## GDPR



Regulamentul european privind protecția datelor cu caracter personal.



\---



\## DORA



Regulamentul european privind reziliența operațională digitală în sectorul financiar.



\---



\# 4. Technical Terms



\## API



Interfață software utilizată pentru schimbul de informații între aplicații.



\---



\## REST



Stil arhitectural utilizat pentru dezvoltarea API-urilor.



\---



\## JWT



Token utilizat pentru autentificare și autorizare.



\---



\## RBAC



Model de control al accesului bazat pe roluri.



\---



\## DTO (Data Transfer Object)



Obiect utilizat pentru transferul datelor între componente.



\---



\## Entity



Reprezentarea unei entități persistente în baza de date.



\---



\## Repository



Componentă responsabilă cu accesul la baza de date sau, în context Git, depozit de cod sursă și documentație.



\---



\## ORM (Object Relational Mapping)



Tehnologie care facilitează accesul la baza de date prin obiecte.



\---



\## Prisma



ORM-ul standard utilizat în aplicațiile ESTINVEST.



\---



\## Docker



Platformă pentru containerizarea aplicațiilor.



\---



\## Git



Sistem distribuit de control al versiunilor.



\---



\## GitHub



Platforma oficială utilizată pentru găzduirea repository-urilor.



\---



\# 5. Architecture Terms



\## Module



Componentă funcțională a unei aplicații.



\---



\## Service



Componentă software care implementează logica de business.



\---



\## Component



Element reutilizabil al unei aplicații.



\---



\## Microservice



Serviciu independent care implementează o funcționalitate bine delimitată.



\---



\## Gateway



Componentă care realizează integrarea cu sisteme externe.



\---



\## Connector



Adaptor software utilizat pentru comunicarea dintre două sisteme.



\---



\## Shared Library



Bibliotecă reutilizabilă utilizată de mai multe aplicații.



\---



\# 6. AI Terms



\## AI Assistant



Instrument AI utilizat pentru asistarea dezvoltării și documentării.



\---



\## Prompt



Instrucțiune transmisă unui model AI.



\---



\## Prompt Engineering



Procesul de proiectare și optimizare a prompturilor.



\---



\## RAG (Retrieval-Augmented Generation)



Tehnică prin care un model AI utilizează documentația internă pentru generarea răspunsurilor.



\---



\## LLM (Large Language Model)



Model lingvistic de mari dimensiuni utilizat pentru procesarea limbajului natural.



\---



\## Ollama



Platformă pentru rularea locală a modelelor LLM.



\---



\## Open WebUI



Interfață web pentru utilizarea modelelor AI locale.



\---



\# 7. Documentation Terms



\## ADR (Architecture Decision Record)



Document care descrie o decizie importantă de arhitectură.



\---



\## Standard



Document care definește reguli obligatorii aplicabile întregului ecosistem.



\---



\## Template



Șablon utilizat pentru crearea documentelor standardizate.



\---



\## Roadmap



Plan de dezvoltare pe termen mediu și lung.



\---



\## Repository Structure



Organizarea directoarelor și fișierelor unui repository.



\---



\# 8. Versioning Terms



\## Major Version



Versiune care introduce modificări incompatibile.



\---



\## Minor Version



Versiune care introduce funcționalități noi compatibile.



\---



\## Patch Version



Versiune care conține remedieri fără modificări funcționale.
