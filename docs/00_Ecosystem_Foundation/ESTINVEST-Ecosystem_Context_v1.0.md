\# 1. Purpose



Acest document oferă contextul minim necesar pentru reluarea unui proiect din cadrul ESTINVEST Ecosystem într-o conversație nouă cu un asistent AI.



Nu înlocuiește documentația proiectului și nici standardele ecosistemului. El reprezintă un rezumat executiv.



\---



\# 2. Ecosystem Overview



ESTINVEST Ecosystem este un ansamblu de aplicații dezvoltate pentru digitalizarea activității unui SSIF.



Componentele principale sunt:



\- ESTINVEST Onboarding

\- ESTINVEST BackOffice Core

\- ESTtrade

\- ESTINVEST Gateway

\- Arena Gateway Simulator

\- Reporting Service

\- Notification Service

\- AI Services

\- Shared Libraries



\---



\# 3. Enterprise Repository



Repository-ul \*\*ESTINVEST-Ecosystem\*\* conține documentația comună pentru toate aplicațiile.

\# 5. Development Principles



Toate proiectele respectă principiile definite în ECO-009:



\- Architecture First

\- Documentation First

\- Security by Design

\- API First

\- Single Source of Truth

\- Modular Architecture

\- Reuse Before Build

\- AI Assisted Development

\- Continuous Improvement

\# 6. Enterprise Standards



Standardele principale sunt:



\- STD-APP-001 – Application Documentation Standard

\- STD-API-001 – API Design Standard

\- STD-DB-001 – Database Design Standard

\- STD-SEC-001 – Security Standard

\- STD-GIT-001 – Git Workflow Standard

\- STD-DEV-001 – Development Workflow Standard

\- STD-AI-001 – AI Development Standard

\- STD-NAM-001 – Naming Convention Standard

\- STD-COD-001 – Coding Standard



Toate proiectele trebuie să respecte aceste standarde.
