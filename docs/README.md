\# Documentation



\## Scop



Folderul \*\*docs\*\* conține documentația oficială a arhitecturii \*\*ESTINVEST Ecosystem\*\*.



Documentația reprezintă sursa principală de informații pentru proiectarea, dezvoltarea și mentenanța întregului ecosistem software.



Toate documentele sunt scrise în format Markdown și sunt gestionate prin Git.



\---



\# Structura



```text

docs

│

├── 00\_Ecosystem\_Foundation

├── 01\_Applications

├── 02\_Integration

├── 03\_Data

├── 04\_Security

├── 05\_System\_Architecture

└── 06\_AI\_Context

```



\---



\# Conținut



\## 00\_Ecosystem\_Foundation



Conține documentele fundamentale ale arhitecturii:



\* Context

\* System Landscape

\* Data Ownership

\* Integration Architecture



Aceste documente trebuie citite înaintea tuturor celorlalte.



\---



\## 01\_Applications



Documentația fiecărei aplicații:



\* Onboarding

\* BackOffice

\* ESTtrade

\* Gateway

\* Reporting

\* Notification

\* AI Services



\---



\## 02\_Integration



Descrierea tuturor integrărilor dintre aplicații și sistemele externe.



\---



\## 03\_Data



Modelele de date, regulile de proprietate și documentația bazelor de date.



\---



\## 04\_Security



Politicile și arhitectura de securitate.



\---



\## 05\_System\_Architecture



Documentația tehnică privind arhitectura software.



\---



\## 06\_AI\_Context



Contextul utilizat pentru colaborarea cu modelele AI.



Include:



\* ChatGPT

\* Claude

\* Cursor

\* Shared Context



\---



\# Reguli



Toate documentele trebuie să respecte șabloanele oficiale din folderul `templates`.



Nu se creează documente fără identificator unic.



Exemple:



\* ECO-001

\* APP-001

\* ADR-001

\* STD-001

\* PROMPT-001



\---



\# Ordinea recomandată de citire



1\. ECO-001 – Ecosystem Context

2\. ECO-002 – System Landscape

3\. ECO-003 – Data Ownership Matrix

4\. ECO-004 – Integration Architecture

5\. Documentația aplicațiilor

6\. Standardele

7\. ADR-urile



\---



\# Convenții



\* un singur fișier pentru fiecare document;

\* versiunea este gestionată în interiorul documentului;

\* istoricul modificărilor este păstrat în Git;

\* toate documentele sunt redactate în limba română, cu termeni tehnici consacrați în limba engleză.



\---



\# Obiectiv



Scopul acestui folder este menținerea unei documentații complete, coerente și actualizate pentru întregul \*\*ESTINVEST Ecosystem\*\*.
