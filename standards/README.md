\# Standards



\## Scop



Folderul \*\*standards\*\* conține toate standardele oficiale utilizate în cadrul \*\*ESTINVEST Ecosystem\*\*.



Aceste documente definesc regulile obligatorii pentru proiectarea, dezvoltarea, testarea, documentarea și operarea aplicațiilor.



Respectarea acestor standarde asigură consistența întregului ecosistem software.



\---



\# Structura



```text

standards

│

├── 00\_Project\_Methodology

├── AI

├── Coding

├── Documentation

├── Git

├── Naming

└── Security

```



\---



\# Conținut



\## 00\_Project\_Methodology



Metodologia oficială de dezvoltare a proiectului.



Exemple:



\* STD-000 – Project Working Method



\---



\## AI



Standarde privind utilizarea instrumentelor AI.



Exemple:



\* AI Working Method

\* AI Collaboration Guide

\* Prompt Engineering

\* AI Review Process



\---



\## Coding



Reguli privind:



\* stilul codului;

\* organizarea proiectelor;

\* convențiile de programare;

\* structura modulelor;

\* gestionarea erorilor.



\---



\## Documentation



Standarde pentru:



\* documentație;

\* nomenclatură;

\* versionare;

\* structură;

\* șabloane.



\---



\## Git



Standarde privind:



\* branch-uri;

\* commit-uri;

\* pull request-uri;

\* versionare;

\* release-uri.



\---



\## Naming



Convenții privind denumirea:



\* fișierelor;

\* directoarelor;

\* modulelor;

\* claselor;

\* tabelelor;

\* API-urilor;

\* documentelor.



\---



\## Security



Standarde privind:



\* autentificare;

\* autorizare;

\* RBAC;

\* criptare;

\* audit;

\* protecția datelor;

\* gestionarea secretelor.



\---



\# Reguli generale



Toate standardele:



\* utilizează șablonul `STD\_Template.md`;

\* au identificator unic (`STD-xxx`);

\* sunt versionate;

\* sunt revizuite periodic;

\* trebuie respectate în toate repository-urile din ESTINVEST Ecosystem.



\---



\# Relația cu celelalte foldere



\* \*\*docs/\*\* definește arhitectura.

\* \*\*standards/\*\* definește regulile.

\* \*\*templates/\*\* definește șabloanele.

\* \*\*prompts/\*\* definește modul de colaborare cu instrumentele AI.

\* \*\*adr/\*\* documentează deciziile de arhitectură.
